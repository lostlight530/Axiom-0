# Daily Research Assets

## Purpose

本目录用于收纳 Axiom-0 日度研究资产

## File Naming

- `YYYY-MM-DD-whitepaper.md`
- `YYYY-MM-DD-archive.md`
- `YYYY-MM-DD-hypotheses.md`

## Expected Flow

```text
automation run
  -> daily node outputs
  -> daily whitepaper
  -> archive snapshot
  -> hypotheses note
  -> ADR candidate extraction
```

## Rule

研究资产允许高密度 神话化 中间态
但最好保留来源状态标签
