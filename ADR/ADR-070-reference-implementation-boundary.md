# ADR-070: Reference Implementation Boundary

## 状态 / Status
Accepted

## 背景 / Context
> **[CN]**: 代码层常被误用为业务逻辑容器。
> **[EN]**: The code layer is often misused as a business logic container.

## 决策 / Decision
> **[CN]**: `CODE/` 目录仅作为 ZECP 协议的参考实现，不承载具体的、非确定性的业务逻辑。
> **[EN]**: The `CODE/` directory serves only as a reference implementation of the ZECP protocol and does not host specific, non-deterministic business logic.
