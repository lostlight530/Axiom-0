# ADR-062 Mythic Generation Lane

- Status: Accepted
- Date: 2026-04-18
- Deciders: lostlight530 + AI copilot
- Scope: Axiom-0 methodology and upstream ideation

## Context

Axiom-0 的上游并不是传统严谨情报系统
它需要一个高压 高频 高密度的灵感喷流环境
当前 Gemini 自动化流程的真实目标 是以现实技术脉络为燃料 生成可命名 可结构化 可继续演化的架构神话

## Decision

正式承认 `Mythic Generation Lane` 为 Axiom-0 的合法上游通道
该通道负责生成

- 新命名
- 新抽象
- 新架构假说
- 新映射关系
- 新日度白皮书草稿

该通道不承担最终真实性定稿职责

## Rationale

- 该项目的核心价值之一 就是把真实技术信号压缩为高密度架构语义
- 先爆发 后脱水 的方法比一开始就保守 更适合当前阶段
- 该通道能持续为 `RESEARCH` 与 `METHODOLOGY` 提供原料

## Constraints

Mythic Generation Lane 输出内容必须可被后续分类为以下四类之一

- REAL
- NEXUS_ORIGINAL
- SPECULATIVE
- FICTIONAL_WRAPPER

## Consequences

正向结果

- 项目不再回避神话生成这一真实工作模式
- 自动化提示词体系拥有了明确定位
- 研究层与方法论层获得持续高压供给

风险

- 未经处理的内容不适合直接对外引用
- 需要更强的后处理与标注机制

## Follow-up

- 在 `METHODOLOGY/` 中明确写出神话生成原则
- 在 `AUTOMATION/` 中固化提示词与标签接口
