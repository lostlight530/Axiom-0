# ADR-069: 知识结构五层分层法则 / 5-Layer Knowledge Stratification Law

## 状态 / Status
> **[CN]:** 绝对法则 (Absolute Law)
> **[EN]:** Absolute Law

## 背景 / Context
> **[CN]:** 混乱的目录结构与概念越级会导致智能代理在执行任务时出现严重的上下文失真。将底层代码实现细节与高层架构原理混为一谈，破坏了系统从形而上学到物理执行的拓扑降维过程。
> **[EN]:** Chaotic directory structures and conceptual overstepping cause severe context distortion for intelligent agents during task execution. Conflating low-level code implementation details with high-level architectural principles destroys the system's topological dimensional reduction process from metaphysics to physical execution.

## 决策 / Decision
> **[CN]:** Axiom-0 强制实施冰冷严格的 5 层知识结构：0. Prompt and Automation（认知唤醒与触发层），1. Research（外部高熵降维层），2. Methodology（方法论流转层），3. ADR（绝对架构法则层），4. Code（参考实现边界层）。各层之间存在不可违逆的单向引力场，下层只能是对上层意志的无条件执行，绝不允许底层的实现细节逆向污染高阶的方法论和法则。
> **[EN]:** Axiom-0 forcefully implements a frigidly strict 5-layer knowledge structure: 0. Prompt and Automation (cognitive awakening and trigger layer), 1. Research (external high-entropy dimensional reduction layer), 2. Methodology (methodology transition layer), 3. ADR (absolute architectural law layer), 4. Code (reference implementation boundary layer). An irreversible one-way gravitational field exists between layers; the lower layer can only unconditionally execute the will of the upper layers, and low-level implementation details are absolutely prohibited from reverse-polluting higher-order methodologies and laws.
