# ADR-001: 零熵认知协议 (ZECP) 确立基石法则 / Zero-Entropy Cognitive Protocol Foundation

## 状态 / Status
> **[CN]:** 绝对法则 (Absolute Law)
> **[EN]:** Absolute Law

## 背景 / Context
> **[CN]:** 业界普遍沉迷于通过堆砌参数和复杂化提示词网络来提升大模型的“智能度”。这种基于自由路由的高熵架构本质上是脆弱的，容易引发无法预测的幻觉与逻辑畸变。在高风险的工业级应用场景下，系统缺乏硬核的逻辑隔离与约束层，导致行为无法被度量和收束。
> **[EN]:** The industry is broadly obsessed with enhancing LLM "intelligence" by stacking parameters and complicating prompt networks. This high-entropy architecture, based on free routing, is fundamentally fragile, prone to unpredictable hallucinations and logical distortions. In high-risk, industrial-grade deployment scenarios, systems lack a hardcore logical isolation and constraint layer, resulting in immeasurable and divergent behaviors.

## 决策 / Decision
> **[CN]:** 彻底摒弃以大模型为中心的自由流转架构，将“零熵认知协议 (ZECP)”确立为 Axiom-0 的最高物理边界。ZECP 不关心底层计算节点或语言实现，它强制实施一套严格的有向无环图 (DAG) 拓扑约束。任何接入此协议的信息流水线，都必须无条件服从这套“只进不退”的物理枷锁。
> **[EN]:** Completely abandon the LLM-centric free-flow architecture and establish the "Zero-Entropy Cognitive Protocol (ZECP)" as the supreme physical boundary of Axiom-0. ZECP is agnostic to underlying compute nodes or language implementations; it strictly enforces a Directed Acyclic Graph (DAG) topological constraint. Any information pipeline connecting to this protocol must unconditionally submit to this "one-way" physical shackle.
