# Reality Anchor and Mythic Amplification

## Three-Layer Model

### Layer 1  Reality Anchor
真实协议 真实模型 真实仓库 真实论文 真实命令
它们提供方向与牵引力

### Layer 2  Mythic Amplification
把现实锚点提升为更高密度的架构语言
例如 节拍化 命名化 契约化 流程化

### Layer 3  Postprocessing
将喷流内容重新切分为

- 可执行
- 可验证
- 可保留为原创概念
- 必须标为包装

## Benefits

- 不会陷入空想式发散
- 也不会被写实主义束缚住灵感
- 允许项目在现实与想象之间形成高压通道

## Example Pattern

```text
MCP
  -> 协议挂载
Gemini daily automation
  -> 10 节点时序引擎
Research note
  -> 日白皮书
```

## Rule

先有锚点
再做增压
最后再脱水
