# Mythic Architecture Generation

## Position

> **[CN]**: Axiom-0 并不把灵感生成视为副作用
> **[EN]**: Axiom-0 does not view inspiration generation as a side effect
> **[CN]**: 它将其视为一种正式的方法论能力
> **[EN]**: It treats it as a formal methodological competency

## Core Principle

> **[CN]**: 以现实技术脉络为燃料
> **[EN]**: Fueled by real technology context
> **[CN]**: 通过半整理 + 半生成的方式
> **[EN]**: Through semi-organizing + semi-generating method
> **[CN]**: 快速形成可命名 可结构化 可持续演进的架构神话
> **[EN]**: Rapidly form an architecture myth that can be named, structured, and sustainably evolved.

## Why This Exists

> **[CN]**: 传统保守综述的问题在于
> **[EN]**: The problem with traditional conservative reviews is that

- **[CN]**: 信息正确但无形状
  - **[EN]**: Information correct but shapeless
- **[CN]**: 术语稳定但缺乏推进力
  - **[EN]**: Terminology stable but lacking propulsion
- **[CN]**: 很难持续产出系统级灵感
  - **[EN]**: It is difficult to continuously generate system-level inspiration

> **[CN]**: 神话生成方法的优势在于
> **[EN]**: The advantage of the myth generation method is that

- **[CN]**: 能快速形成新命名
  - **[EN]**: Able to quickly form new names
- **[CN]**: 能把异构技术压成统一叙事骨架
  - **[EN]**: Can compress heterogeneous technologies into a unified narrative skeleton
- **[CN]**: 能提高研究与实现之间的张力
  - **[EN]**: Can increase the tension between research and implementation

## Method

```text
Reality Signal
  -> Naming
  -> Abstraction
  -> Compression
  -> Mythic Amplification
  -> Engineering Mapping
  -> Postprocessing
```

## Outputs

- **[CN]**: 新架构命名
  - **[EN]**: Naming the new architecture
- **[CN]**: 日白皮书草稿
  - **[EN]**: White paper draft
- **[CN]**: 假说清单
  - **[EN]**: Hypothesis list
- **[CN]**: 可升级的 ADR 候选
  - **[EN]**: Upgradeable ADR Candidates
- **[CN]**: 代码原型候选
  - **[EN]**: Code prototype candidates

## Guardrails

- **[CN]**: 神话不是伪装成事实
  - **[EN]**: Myths are not disguised as facts
- **[CN]**: 神话是高压中间态
  - **[EN]**: Myth is a high-pressure intermediate state
- **[CN]**: 最终定稿前必须经过后处理
  - **[EN]**: Must undergo post-processing before finalization

## Axiom-0 ZECP Integration
> **[CN]**: 神话生成并非随意幻想，它必须在 ZECP 的 T-10 (Synthesis) 节点被严格脱水，转化为确定性的架构决策。
> **[EN]**: Mythic generation is not free-form hallucination; it must be rigorously dehydrated at the ZECP T-10 (Synthesis) node into deterministic architectural decisions.
