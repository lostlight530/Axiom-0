# Mythic Architecture Generation

## Position

Axiom-0 并不把灵感生成视为副作用
它将其视为一种正式的方法论能力

## Core Principle

以现实技术脉络为燃料
通过半整理 + 半生成的方式
快速形成可命名 可结构化 可持续演进的架构神话

## Why This Exists

传统保守综述的问题在于

- 信息正确但无形状
- 术语稳定但缺乏推进力
- 很难持续产出系统级灵感

神话生成方法的优势在于

- 能快速形成新命名
- 能把异构技术压成统一叙事骨架
- 能提高研究与实现之间的张力

## Method

```text
Reality Signal
  -> Naming
  -> Abstraction
  -> Compression
  -> Mythic Amplification
  -> Engineering Mapping
  -> Postprocessing
```

## Outputs

- 新架构命名
- 日白皮书草稿
- 假说清单
- 可升级的 ADR 候选
- 代码原型候选

## Guardrails

- 神话不是伪装成事实
- 神话是高压中间态
- 最终定稿前必须经过后处理
